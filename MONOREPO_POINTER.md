Tämä hakemisto on **väliaikaisesti** `opendoorsfi/moderate`-monorepossa.

**Tuotanto:** [`opendoorsfi/hermes-google-chat`](https://github.com/opendoorsfi/hermes-google-chat) (erillinen repo).

**Älä sekoita** [`opendoorsfi/moderate`](https://github.com/opendoorsfi/moderate) kommenttimoderointiin (`chat-moderation`, Zapier, Sheet).

Moderate-repossa **ei enää** `.github/workflows/hermes-google-chat-*.yml`.

Export → [docs/CREATE_REPO.md](docs/CREATE_REPO.md):

```bash
bash scripts/export_hermes_google_chat_repo.sh   # moderate-juuresta
```
