# Open Doors Hermes profile

Väliaikainen profiili kunnes `opendoorsfi/kanava-ux` on luettavissa.

- **config.yaml** — system prompt, model, toolsets
- Päivitä [`docs/KANAVA_UX_MAPPING.md`](../../docs/KANAVA_UX_MAPPING.md) kun speksi saadaan

Deploy kopioi profiilin `HERMES_HOME/profiles/opendoors/` entrypointissa.
